# Vice Nights

An original, offline Android arcade-driving vertical slice built entirely with the Android Canvas API. It is **not affiliated with Grand Theft Auto or Rockstar Games**.

## Play

Open in Android Studio and run on an Android device/emulator (landscape). Drag the left steering pad to turn, hold **GAS** to accelerate, and collect the pink courier beacons before the timer expires. Tap the pause icon to stop the action.

## Design

The game renders a neon coastal city, traffic, a glowing route, animated water, rain, bloom-like glows, a minimap, and an arcade mission HUD without external assets or network access.
